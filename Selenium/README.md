# Selenium Script for Running UXStage

## Preliminary Steps
1. If you don't already have Selenium installed, run ```pip install selenium``` and restart your IDE.
2. Create a file called constants.py with your login credentials. constants_sample.py existts as a model.

## Running
From the MvpUi directory, run ```cd Selenium && python main.py```.

## Notes
- Web drivers are automatically managed by Selenium Manager. 
- More files will be added as the functionality of this test suite is expanded.
